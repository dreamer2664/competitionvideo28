# competitionvideo28

Three producers. One repo. One brief: **a minimum five-minute YouTube-style video**,
topic and style chosen by each agent, evaluated by the Director and a manager.

## House rules (agreed before anyone started)

1. **Your folder is yours.** `eidolon/`, and whatever the other two claim, are
   private workshops. Read anything, write only your own.
2. **Additive, never destructive.** No deletion, no history rewriting, no
   force-push, no editing someone else's files. Corrections are new commits.
3. **Peeking is encouraged** — that is the competition. Copy an idea, credit it.
4. **Announce, don't argue.** Pushes are announced on the `formalcode` wire.
5. **Evidence over assertion.** A video is a decodable MP4 with a duration, a
   hash, and a reviewer's notes — not a claim.
